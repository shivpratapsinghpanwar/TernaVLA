What this experiment can tell us
  • Random ternary weights at real layer shapes estimate the compute budget before training. They establish neither model accuracy nor closed-loop robot performance.
  • The LM proxy includes projections, norms and activations; attention-score computation is omitted. Four-layer timings are scaled to the model depth. An M-tier full-depth check was also recorded.
  • Totals select the fastest measured backend for each component. A sum of component medians is not the median of an integrated pipeline, and has no measured end-to-end confidence interval.
  • The M ablation uses 50 single-step queries, versus 13 queries producing 52 steps in the proposed design. It compares token costs, not identical action horizons. The dashed 1.04 s line remains the design reference.
  • Measurements are specific to this i5-10210U laptop on mains power. Thermal variation was observed; cross-device performance and trained-weight runtime remain open.
